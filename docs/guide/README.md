# The woodshed guide

Everything the [front page](../../README.md) leaves out, by what you want to do.

- [Install, update, uninstall](install.md): every way to install, the warnings the first time,
  Intel Macs, M4A files, updating and uninstalling.
- [For singers](singers.md): the words with the chords above them, your voice type, the recording
  in your key.
- [Your part](parts.md): each instrument's panel, what is measured and how sure, practising, the
  keyboard.
- [The chart: check it, fix it](editing.md): check by ear, edit a bar, bar lines, key changes.
- [The band: phones, stage and set list](phones.md): the band's phones, stage mode, the set list,
  screens kept on, HTTPS.
- [Your library and your exports](exports.md): ChordPro, MIDI, MusicXML, print, sharing a song.
- [How it works](how-it-works.md): the analysis, how accurate it is, privacy, the models and their
  licences, credits.
- [When something goes wrong](troubleshooting.md): the messages woodshed shows and what to do.

What changed in each version: the [changelog](../../CHANGELOG.md). For developers:
[contributing](../../CONTRIBUTING.md) and [under the hood](../architecture.md).
